Offrpath

Practice for the coding interview where the AI writes the code.

Live, in progressEdTechAI

Problem

Coding interviews are shifting from writing code to judging it. An AI can write a working function in seconds, but some of what it writes is buggy or unsafe, and the skill being tested is knowing which.

What it does

You review simulated pull requests from an AI assistant and flag lines as bugs, edge cases, security holes, performance issues, or readability problems. It shows what you caught and missed, line by line, and later PRs target your weak spots. A second mode, Trust or Reject, asks whether to accept, reject, or modify the AI's code.

Next.js, React, Supabase (Postgres), Vercel

Claude Trading Agent

A swing-trading bot that runs unattended on GitHub Actions. No server.

+98.5% in a 2-year backtest254 stocks screened weeklyFinTech

Problem

Swing trading needs constant screening, sentiment reading, and disciplined execution, which is easy to do inconsistently by hand.

What it does

Scans 254 large-cap stocks every week for trend and dip signals, layers in news and social sentiment, then places risk-managed orders on Alpaca and posts P&L to Discord.

Python, pandas, alpaca-py, Groq (Llama 3.3 70B), Claude, GitHub Actions, Discord webhooks

Tavio

Restaurant discovery that works for blind and visually impaired diners.

4th statewide, NJ TSAAccessibilityREST API

Problem

Finding a restaurant that fits your needs is hard when you can't scan a menu by sight.

What it does

Finds nearby places through Google Places, adds travel time from Google Routes, and returns the top three matches for a user's cuisine, dietary, allergen, spice, price, and travel-time preferences.

FastAPI, PostgreSQL, SQLAlchemy, Pydantic, Google Places and Routes APIs
